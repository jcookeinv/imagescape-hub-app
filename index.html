Key deadlines

Worked out from the financial year end and confirmation statement date above, plus the fixed UK Self Assessment dates. This is a reminder tracker, not a filing service — each deadline still needs filing directly with HMRC or Companies House (or via your accountant).

Financial snapshots

Zoho Books can't be reached directly from this page (it doesn't support cross-origin browser calls the way WordPress does), so snapshots are imported instead: ask Claude, in a session with Zoho connected, to pull the latest figures and generate an import file — then bring it in here. See SETUP.md for the exact format if you want to build one by hand.

Proactive reminders

Whenever you save, this sends a small, unencrypted copy of open tasks' due dates and the deadlines above to a Google Apps Script you control — a daily check there pushes a notification via ntfy.sh if anything's overdue or coming up. Nothing else (notes, credentials, financial figures, meeting content) ever leaves the vault. See SETUP.md section 8 for the one-time Apps Script setup.
Not connected
Deploy the Apps Script as a Web App (see SETUP.md section 8), then paste its URL and the shared secret you set in the script's Project Settings → Script Properties here.
Because of how Apps Script's cross-origin handling works, the Hub can't confirm the sync actually succeeded — only that it was sent. The first time you connect, click Sync now, then check the Reminders folder in Drive directly to confirm reminders.json appeared and updated.
